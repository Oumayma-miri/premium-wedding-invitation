# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/)

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).

## Expanding the ESLint configuration

If you are developing a production application, we recommend using TypeScript with type-aware lint rules enabled. Check out the [TS template](https://github.com/vitejs/vite/tree/main/packages/create-vite/template-react-ts) for information on how to integrate TypeScript and [`typescript-eslint`](https://typescript-eslint.io) in your project.

# 💍 Premium Wedding Invitation

An elegant, interactive and customizable digital wedding invitation designed to transform a traditional wedding invitation into a beautiful web experience.

Built with **React, Vite, Tailwind CSS and Motion**, the project focuses on elegant UI/UX, smooth animations, responsive design and reusable architecture.

The invitation is designed as a **reusable system**, allowing different couples to customize their names, photos, wedding information, colors, decorations and sections without rewriting the core application.

## ✨ Planned Features

* 💌 Interactive envelope opening experience
* 💍 Customizable bride & groom information
* 📸 Responsive photo gallery with lightbox
* 📅 Wedding ceremony & reception details
* 📍 Interactive venue/location section
* 👗 Customizable dress code
* 💌 RSVP / attendance confirmation
* 💬 Guest wishes and messages
* 🦋 Customizable decorative elements
* 🌹 Configurable flowers, petals and ornaments
* 🎨 Centralized theme and color system
* Google Maps / OpenStreetMap *(planned)*

## 🎯 Project Goal

The goal is to create a reusable digital wedding invitation system rather than a single static website.

Wedding-specific information is separated from the UI so that a new invitation can be created by changing configuration data instead of rebuilding the application.

```text
Wedding Configuration
        ↓
Reusable React Components
        ↓
Custom Theme & Decorations
        ↓
Interactive Wedding Experience
```

## 📌 Status

🚧 **In Development**

The project is currently being developed progressively, with a focus on creating a strong foundation before implementing backend functionality such as RSVP storage and guest wishes.
